# Stereo wallpapers

Seamlessly looping 3D video wallpapers for [Sparky Stereo OS](https://github.com/Sparky-OS/sparky-stereo-os),
played by the [org.kde.video](https://github.com/Sparky-OS/org.kde.video) wallpaper plugin.
They're generated by small Python scripts, so you can rebuild them, change them, or render other sizes.

| Wallpaper | What it is |
|---|---|
| **particles** | About 420 pale motes drifting slowly through a deep volume on a near-black background. Near ones are bigger, brighter and move more. |
| **waves** | A dark blue-gray sheet with a soft grid and fine grain, swelling gently in four overlapping waves. |

The rendered clips are attached to each [release](https://github.com/halverneus/stereo-wallpapers/releases), not kept in git.

## Format

- Side-by-side full width, 3840x1080 (1920x1080 per eye), **left eye on the left**. The Matroska `stereo_mode=left_right` tag is set.
- 30 fps and 12 s. Every motion completes a whole number of cycles in that time, so the last frame flows into the first with no jump.
- H.264 yuv420p.
- Each `-anaglyph.mp4` is a red/cyan (Dubois) preview that plays in any video player. Wear the red lens on the left eye.

## Depth

Sparky Stereo OS treats the desktop as a sunk box: the wallpaper sits behind the screen, and windows sit in front of it.
So nothing in these clips comes out of the screen. Disparity runs from +4 px (nearest, just behind the glass) to +40 px (farthest), measured at 1920 px per eye, and is never negative.

The colors are kept pale and low-saturation, because strong color fights red/cyan glasses.
In waves, the vertical grid lines are 128 px apart, well beyond the 40 px maximum disparity, so the eyes can't fuse the wrong pair of lines.

## Building

```sh
python3 -m venv .venv && .venv/bin/pip install numpy
PYTHON=.venv/bin/python ./build.sh            # or: ./build.sh particles
```

This writes `out/<name>-sbs.mkv`, `out/<name>-anaglyph.mp4` and `out/SHA256SUMS`.
It needs an ffmpeg with libx264 and the `stereo3d` filter.
Rendering particles takes about a minute; waves takes a few.

Each clip records its provenance in its own tags: title, artist, license, this repository, the script, and the commit it was built from.

```sh
ffprobe -v error -show_entries format_tags out/particles-sbs.mkv
```
